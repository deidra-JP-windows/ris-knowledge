# 標準偏差
- データが平均値の周辺でどれくらいばらついているかを表す
  - データの特徴を要約する基本統計量の一つ
  - データが平均値周辺で収まっている場合 → 45 50（平均値）65
    - データのばらつきが小さい
  - データが平均値周辺で収まっていない場合 → 15 30 45 50（平均値）65 80 95 110
    - データのばらつきが大きい
  - X, y 軸それぞれで標準偏差を見れる

# 回帰分析
## 回帰分析は「ある結果（売上など）が、どの要因（広告費など）によって、どのくらい変わるか」を数式で表して分析・予測する統計手法
### 量的変数などを使用
### 直接時系列データは使用せず、1日・２日・3日や曜日などのデータに変換されつかわれる

# 回帰係数
- 「説明変数が1単位変化したときに、目的変数が平均でどれだけ変化するか」を示す値

# 量的変数
## 量や数値を表す数値データ。計算が可能で、統計解析に適している。(例：身長、体重、売上など)
  - 説明変数
    - 目的変数に影響すると考える要因（例：広告費、来店客数、駅からの距離など）
    - 量的変数の一種
  - 目的変数
    - 予測したい・説明したい結果のこと（例：売上、アクセス数、温度など）
    - 量的変数の一種
  - 尺度
    - 物事を評価するための基準
    - 量的変数 or 質的変数 のカテゴリに分類される
    - 変数の性質を分類する枠組み
    - 結果（目的変数）に対して、要因（説明変数）がどの程度影響しているかを数式で表す分析手法。
  - 間隔尺度
    - 量的変数
    - 大小・差に意味あり、0は相対的（絶対0でない）。
    - 温度（℃）、西暦、偏差値
  - 比例尺度
    - 量的変数
    - 大小・差・比率に意味あり、0は絶対的（無を意味）。
    - 身長、価格、時間、人数
  - 名義尺度
    - 質的変数
    - 分類のみ可能。大小関係なし。
    - 性別、血液型、郵便番号
  - 順序尺度
    - 質的変数
    - 大小関係あり（順位）が、間隔に意味なし
    - ランキング、満足度（高・中・低）

# 有意変数
- 「目的変数に有意な影響あり」と判定された説明変数

# 質的変数
## カテゴリーや属性を表す非数値データ。計算（足し算など）ができない。(例：性別、色、職業など)

# 相関分析（相関）
- 2つの変数が「一緒に増えたり減ったりする傾向」があるかどうかを表す概念的な言葉。正・負・無相関など。一般には「関係がありそうか」の直感的な話。

## 相関係数
- 相関の「強さ」と「向き（正か負か）」を、数値で表した指標。通常はピアソンの相関係数を指し、値の範囲は -1 ~ 1
- 正の相関はグラフ上だと左から右上に上がっていく
- 府の相関はグラフ上だと右から左上に上がっていく

# 相関分析と回帰分析の関係
- 相関分析と回帰分析は密接に関連している
  - 相関が「関係の有無・強さ」を確認する探索段階、回帰がその関係を予測・因果推定に活用するモデル化段階
- 相関は「関係探し」、回帰は「関係活用」。相関マップ作成→有意変数で回帰、という流れが分析の王道。

# 帰無仮説
- 「何も起きていない／差がない」とみなす仮説
  - 統計の仮説検定で最初に立てる

# 対立仮説
- 「差がある」「効果がある」「関係がある」と主張したい側の仮説

# 検定
- 仮説をデータで“否定できるか”を調べる手続き
  - 実務的には「主に帰無仮説を否定できるかを見る手続き」
  - 「もし帰無仮説が本当に正しいとしたら、今観測したデータはどれくらい珍しいか？」という確率（p値）を計算
    - p値が十分小さい（例：0.05未満）なら、「こんなデータ、帰無仮説が正しい世界では1000回に1回しか起きないレアケース」と判断して帰無仮説を棄却し、対立仮説を支持
      - 差があるということになる
    - p値が大きいときは、「2回に1回普通に出る、ごくありふれた結果で帰無仮説を棄却できない（差があるとは言えない）」と結論づけます。
    - ポイントは「帰無仮説を採択する」のではなく棄却できないだけという立場をとることです。

# 2進数から10進数
1. 2のn乗(0から)を8つほど（よく使う桁数）右から小さい順に並べる
2. 対象の2進数を上下で比較できるように並べる
3. 2進数の数列のうち、1の値と並ぶ2のn乗の値を抜き出す
4. 抜き出した値を足したものが10進数となる
5. 1110 の場合、8,4,2,1 のうち右端を除いた値を足す。14が答え


# 10進数から2進数
1. 10進数の値を2で割っていく
2. 割ったあまりを出していき（1か0）右から並べる
3. 1までこの作業を行ってでた数列が2進数になる
4. 14 の場合、2で割っていくと0,1,1,1となり、右から左詰めで並べると1110が答えとなる

# 16進数から10進数
1. 例：7B3 を 10進数にする
2. 右から桁と重みを書く
3. 3 × 16の0乗(= 1) = 3
4. B(=11) × 16の1乗(= 16) = 176
5. 7 × 16の2乗(= 256) = 1792
6. 全て足して1971になる
7. 「右から順に、桁の値 × 1, 16, 256, 4096,... を足す」
8. 小数点以下は 16の-1乗する（16のx乗の値で割ってあげるだけ）

# サブネットマスクの計算方法
1. n個1を8つ区切りで並べて、残りは32桁まで0を入れる
2. この値を10進数に変換すると、サブネットマスクの10進数表記が得られる
- オクテッド4セグメントでipv4アドレスは成り立っている為、/23 で指定されている場合は23個1を8つ区切りで並べて、残りは32桁まで0を入れる

## 例: 192.168.13.111 の場合
1. サブネットマスク /23 を2進数で表すと `11111111.11111111.11111110.00000000` となる。
2. このサブネットマスクを使い、IPアドレス `192.168.13.111` を2進数に変換すると `11000000.10101000.00001101.01101111` となる。
3. サブネットマスクとIPアドレスのAND演算を行う:
   - サブネットマスク: `11111111.11111111.11111110.00000000`
   - IPアドレス: `11000000.10101000.00001101.01101111`
   - AND結果: `11000000.10101000.00001100.00000000`
   - 簡単に計算すると、サブネットマスク側の0になっているところだけ見て演算すればいい(左詰めで1が並ぶため)
4. AND結果を10進数に戻すと、ネットワーク部は `192.168.12.0` となる。
- ホスト部の範囲:
  - ホスト部のビット数は、サブネットマスクの0の数
  - /23 の場合、32ビット中9ビットがホスト部
  - ホスト部の最小値: 全て0 → 192.168.12.1 (ネットワークアドレスの次)
  - ホスト部の最大値: 全て1 → 192.168.13.254 (ブロードキャストアドレスの前)
  - ホスト部の2進数の例だと、ホスト部を全て全て1にしたのち先端と末尾を0にしたビット列が利用可能なホスト部 `11000000.10101000.00001100.00000001` ~ `11000000.10101000.00001101.11111110`

# ブロードキャストアドレスの計算方法
1. サブネットマスクの計算方法を行う
2. 0の部分だけ抜きだし、全て1に変換
- 8桁に足りないセグメントは左から0を入れておく
3. 変換したセグメントを10進数に変換し、10進数に直してサブネットマスクと足した値がブロードキャストアドレス

# ユークリッドの互除法
最大公約数を求める計算ロジック
function gcd(a, b):
    while b != 0:
        r = a mod b
        a = b
        b = r
    return a
